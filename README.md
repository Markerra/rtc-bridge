# rtc-bridge

локальный мост между источником аудио в браузере.

## Запуск

```powershell
.\gradlew.bat run
```

сервер слушает только `ws://127.0.0.1:25565`, поэтому к нему не может подключиться другое устройство в сети. другой порт: `.\gradlew.bat run --args="25566"`.

## Версия протокола 0

сначала клиент посылает текстовое WebSocket-сообщение:

```json
{"type":"hello","role":"source"}
```

или:

```json
{"type":"hello","role":"consumer"}
```

затем `source` присылает бинарные кадры PCM. каждый кадр должен быть ровно 1920 байт: моно, 48 000 Гц, signed 16-bit little-endian, 20 мс. сервер пересылает кадры всем `consumer`.
